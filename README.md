# 🤲 My Prayer — Doa & Zikir Setelah Sholat Fardhu

Aplikasi web modern, responsif, dan ringan untuk membaca doa serta zikir setelah sholat fardhu. Didesain dengan estetika minimalis menggunakan skema warna Emerald Primary (`#0F5132`) dan Warm Cream (`#FAFAF7`).

---

## ✨ Fitur Utama

- 📖 **Bacaan Sahih & Lengkap**: Meliputi Istighfar, Dzikir Keselamatan, Tahlil, Tasbih/Tahmid/Takbir, Ayat-ayat Al-Qur'an, hingga Doa Pribadi.
- 🔠 **Penyesuai Ukuran Font**: Pengaturan ukuran teks Arab secara dinamis untuk kenyamanan membaca.
- 📱 **Mobile First & PWA Ready**: Tampilan nyaman di layar HP dan dapat diinstal langsung ke Home Screen.
- 🖱️ **Floating Scroll Navigation**: Navigasi cepat berbasis tinggi layar (*viewport height*) untuk kemudahan penggunaan di perangkat seluler.
- 📋 **Utility Actions**: Dukungan tombol Salin (*Copy*), Bagikan (*Share*), dan Simpan (*Bookmark*).

---

## 🛠️ Teknologi yang Digunakan

- **Framework**: [React](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Bahasa**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Ikon**: [Lucide React](https://lucide.dev/)
- **Tipografi**: Google Fonts (*Amiri* & *Plus Jakarta Sans*)
